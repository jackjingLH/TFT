# 图片分割工具

自动将长图按 3:4 比例分割，适合社交媒体发布（小红书、微博等）。

## 功能特性

- ✅ 自动按 3:4 比例分割长图
- ✅ 分片之间有 100px 重叠区域，避免切断文字
- ✅ 保留原始长图不变
- ✅ 自动创建 split 子目录存放分割后的图片
- ✅ 显示详细的分割信息和文件大小

## 使用方法

### 基本用法

```bash
# 在 mdToImg 目录下运行
node splitImage.js <图片路径> [输出目录]
```

### 示例

```bash
# 分割图片到默认目录 (split/)
node splitImage.js test_split.png

# 指定输出目录
node splitImage.js test_split.png ./my_output

# 分割其他目录的图片
node splitImage.js ../output/myimage.png
```

## 分割规则

### 3:4 比例计算

- **宽度**: 1080px（标准移动端宽度）
- **单片高度**: 1440px（1080 ÷ 3 × 4 = 1440）
- **比例**: 每片都是 3:4 或接近 3:4

### 重叠区域

- 相邻分片之间有 **100px 重叠**
- 避免文字被切断
- 阅读更连贯

### 示例（5153px 高的图片）

```
片段 1: 0px ~ 1440px       (1440px, 3:4 完美比例)
片段 2: 1340px ~ 2780px    (1440px, 100px 重叠)
片段 3: 2680px ~ 4120px    (1440px, 100px 重叠)
片段 4: 4020px ~ 5153px    (1133px, 最后一片)
```

## 输出文件命名

```

```

示例：
- `test_split_part1_of_4.png` - 第1片，共4片

- `test_split_part3_of_4.png` - 第3片，共4片

## 配置选项

在 `splitImage.js` 中可以修改配置：

```javascript
const SPLIT_CONFIG = {
  aspectRatio: 3 / 4,  // 宽高比（3:4）
  overlap: 100,        // 重叠像素（避免切断文字）
};
```

### 自定义重叠区域

如果想要更大的重叠区域：

```javascript
overlap: 150,  // 150px 重叠
```

如果不需要重叠：

```javascript
overlap: 0,  // 无重叠
```

## 注意事项

1. **原始文件不变**: 分割不会修改原始长图
2. **输出目录**: 默认创建 `split/` 子目录
3. **文件格式**: 输出格式为 PNG，保持高质量
4. **重叠区域**: 确保内容连贯，但会增加总文件大小

## 技术细节

### 使用的库

- **sharp**: 高性能图片处理库
- 支持大尺寸图片
- 快速裁切和输出

### 性能

- 5000px 高度的图片约需 1-2 秒
- 内存占用低
- 支持任意尺寸

## 完整工作流程

### 1. 生成长图

```bash
cd mdToImg
node mdToImage.js "../translated_guides/xxx.md" "output.png"
```

### 2. 分割长图

```bash
node splitImage.js output.png
```

### 3. 获取分割后的图片

在 `split/` 目录中找到所有分片

### 4. 发布到社交媒体

按顺序发布所有分片，形成完整的攻略

## 故障排除

### 问题：文件不存在

```bash
错误: 文件不存在 - xxx.png
```

**解决**: 检查文件路径是否正确，使用绝对路径或相对路径

### 问题：内存不足

**解决**:
- 关闭其他应用程序
- 处理较小的图片
- 增加 Node.js 内存限制：`node --max-old-space-size=4096 splitImage.js`

### 问题：图片质量下降

**解决**:
- PNG 格式不会损失质量
- 确保使用的是 sharp 库（已自动安装）
