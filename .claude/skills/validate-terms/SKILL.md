# 验证术语

## 概述
根据既定标准、术语准确性和格式要求对TFT.md翻译执行全面的质量验证。

## 使用时机
- 完成翻译后验证质量时
- 检查现有TFT.md的合规性问题时
- 在最终发布翻译攻略之前
- 识别具体的术语或格式问题时

## 验证流程
该技能根据完整的质量清单执行自动验证：

### 检查的质量领域
1. **术语准确性**
   - 英雄名称、装备名称和技能名称
   - 游戏机制术语
   - 地区和阵营名称

2. **格式合规性**
   - 一致的标题结构
   - 正确的列表格式
   - 正确使用markdown元素

3. **内容标准**
   - 语法和可读性
   - 文化适应
   - 游戏特定约定

## 📋 完整验证清单

### ✅ 术语准确性检查
- [ ] **英雄名称**：使用官方中文译名（永恩、艾瑞莉娅、亚索等）
- [ ] **装备名称**：严格对照术语表（朔极之矛、饮血剑、泰坦的坚决等）
- [ ] **羁绊名称**：使用标准格式"羁绊名（数字）"（艾欧尼亚（3）、护卫（6）等）
- [ ] **强化符文**：使用官方译名（装备百宝袋、开金矿、团队建设等）
- [ ] **游戏机制**：准确翻译（刷新商店、慢速刷新、快速升至X级等）
- [ ] **地区阵营**：正确名称（艾欧尼亚、比尔吉沃特、德玛西亚等）

### ✅ 格式合规性检查
- [ ] **标题层级**：
  - 仅使用一级标题（# 文章主标题）
  - 仅使用二级标题（## 🎯 章节标题）
  - **严禁使用三级及以下标题**（### ####）
  - 使用加粗文本替代三级标题（**小节强调**）
- [ ] **列表格式**：
  - 正确使用无序列表（- 项目）
  - 正确使用有序列表（1. 项目）
  - 列表缩进一致
- [ ] **强调格式**：
  - 加粗用于核心名词（**永恩**、**艾瑞莉娅**）
  - 下划线用于重要操作（<u>关键时机</u>）
  - 引用块用于核心观点（> 重要提示）
- [ ] **元数据格式**：
  - 正确的tags格式（<!-- tags: 标签1, 标签2 -->）
  - 正确的cover格式（<!-- cover: 图片路径 -->）
  - 正确的backup格式（<!-- backup: 备份名称 -->）

### ✅ 内容完整性检查
- [ ] **信息完整**：保留所有原始内容，无遗漏
- [ ] **结构完整**：包含完整的攻略结构（定位、条件、节奏、装备、符文）
- [ ] **数据准确**：等级、费用、星级等数字信息准确
- [ ] **来源声明**：包含"来源: XXX"声明

### ✅ 语言规范性检查
- [ ] **书面表达**：已转换为规范的书面攻略语言
- [ ] **去除口语**：已删除语气词（嗯、啊、那个等）
- [ ] **术语统一**：相同术语在全文中保持一致
- [ ] **表达清晰**：句子通顺，逻辑清晰

### ✅ 游戏特定约定检查
- [ ] **数值格式**：
  - 英雄等级：`3星亚索` ✅
  - 费用等级：`3费英雄` ✅
  - 羁绊等级：`艾欧尼亚（3）` ✅
- [ ] **特殊符号**：
  - 使用`/`分隔并列选项（朔极之矛/汲取剑/蓝BUFF）
  - 使用`→`表示因果关系或流程
  - 使用`/`表示"或者"关系

### 🎯 详细检查项

#### 术语准确性验证
- **英雄名称检查**：
  - 永恩 ✓ | 约恩 ✗
  - 艾瑞莉娅 ✓ | 艾瑞莉雅 ✗
  - 亚索 ✓ | 犽凝 ✗

- **装备名称检查**：
  - 朔极之矛 ✓ | 朔极之茅 ✗
  - 饮血剑 ✓ | 血腥之剑 ✗
  - 泰坦的坚决 ✓ | 巨人杀手 ✗

- **羁绊格式检查**：
  - 5比尔吉沃特 ✓ | 比尔吉沃特5 ✗ | 比尔吉沃特（5）✗

#### 格式合规性验证
- **标题层级检查**：
  - 一级标题：# 标题 ✓
  - 二级标题：## 标题 ✓
  - 三级标题：### 标题 ✗ (严禁使用)
  - 替代方案：**标题** ✓

- **强调格式检查**：
  - 加粗：**核心名词** ✓
  - 下划线：<u>重要操作</u> ✓
  - 引用块：> 核心观点 ✓

## 🔍 验证执行流程

### 步骤1：术语准确性验证
1. **英雄名称检查**
   - 扫描所有英雄名称
   - 对照术语表验证准确性
   - 标记错误译名

2. **装备名称检查**
   - 识别所有装备提及
   - 验证官方中文译名
   - 检查装备别名使用

3. **羁绊名称检查**
   - 验证羁绊格式"名称（数字）"
   - 检查羁绊等级表示

### 步骤2：格式合规性验证
1. **标题层级扫描**
   - 检测标题标记（# ## ###）
   - 识别违规三级标题
   - 建议替代格式

2. **强调格式检查**
   - 验证加粗使用场景
   - 检查下划线使用
   - 确认引用块应用

3. **列表格式验证**
   - 检查列表符号一致性
   - 验证缩进格式

### 步骤3：内容完整性验证
1. **信息完整性检查**
   - 对比源文件内容
   - 确认无信息遗漏
   - 验证数据准确性

2. **结构完整性验证**
   - 检查攻略结构完整
   - 验证章节完整性

## 🛠️ 自动修正功能

### 常见自动修复
- **格式问题**：
  - 三级标题 → 加粗文本
  - 错误缩进 → 标准缩进
  - 列表符号统一

- **术语替换**：
  - "约恩" → "永恩"
  - "巨人杀手" → "泰坦的坚决"
  - "血量" → "生命值"

### 手动审查建议
- **复杂问题标记**：
  - 上下文相关术语
  - 文化适应问题
  - 表达优化建议

- **优先级分类**：
  - **[紧急]** 术语错误
  - **[重要]** 格式违规
  - **[建议]** 表达优化

## 📝 常见问题示例

### ❌ 典型错误案例

#### 术语错误
```markdown
✗ 错误：约恩 + 艾瑞莉雅
✓ 正确：永恩 + 艾瑞莉娅

✗ 错误：朔极之茅 / 血腥之剑
✓ 正确：朔极之矛 / 饮血剑

✗ 错误：比尔吉沃特5 / 比尔吉沃特（5）
✓ 正确：5比尔吉沃特
```

#### 格式违规
```markdown
✗ 错误：### 装备推荐
✓ 正确：**装备推荐**

✗ 错误：#### 核心装备
✓ 正确：**核心装备**

✗ 错误：使用*斜体*作为标题
✓ 正确：使用**加粗**作为小节标题
```

#### 表达不当
```markdown
✗ 错误：这个阵容很猛，随便打打就赢了
✓ 正确：这个阵容非常强力，操作相对简单

✗ 错误：嗯...前期的话，那个...
✓ 正确：前期阶段优先...
```

## 💡 使用提示

### 最佳实践
1. **翻译后立即验证**：完成翻译后第一时间运行验证
2. **逐项修正**：按照验证报告逐项修正问题
3. **重新验证**：修正后重新运行确保问题解决
4. **记录问题**：记录常见错误避免重复

### 验证时机
- ✅ 完成初步翻译后
- ✅ 修改重要术语后

- **重点检查**：优先检查术语和格式
