# 📝 TFT游戏攻略文本规范化

## 任务说明
这是一个游戏内容处理任务:将云顶之弈(TFT)的中文攻略文本进行标准化,修正语音识别错误的游戏术语。

## 处理步骤

### 第1步:读取和分析
首先读取以下文件以了解任务范围:
- `TFT.txt` - 待处理的游戏攻略原文
- `docs/terms/zh_terms.csv` - 游戏术语标准对照表(前50行)
- `docs/protocols/translation-protocol.md` - 文本处理规范(仅读取关键部分)

**注意**:仅读取文件,不执行任何处理

### 第2步:术语识别
根据 `docs/protocols/translation-protocol.md` 第3节"分层术语处理算法",识别原文中需要纠正的游戏术语:
- 英雄名称(如:卡莎、盖伦、波比)
- 装备名称(如:洋刀→鬼索的狂暴之刃)
- 羁绊名称(如:护卫、狙神、巨神)
- 游戏俚语(如:D牌→刷新商店)

### 第3步:生成纠错清单
创建一个术语纠错记录清单,格式:
```
- [类型] 原文: "xxx" -> 纠正: "yyy"
```

### 第4步:生成规范化文本
应用纠错清单,生成规范化后的攻略文本:
- 替换错误术语为标准术语
- 统一羁绊格式为"羁绊名(数字)"
- 去除口语词(嗯、啊、那个等)
- 优化段落结构

### 第5步:输出文件
按照 `docs/protocols/translation-protocol.md` 第6节"输出协议"格式,生成:
- `docs/protocols/TFT_processed.md` - 完整处理记录(纠错记录+原文+规范文本)
- `TFT.md` - 仅规范化后的文本

## 执行方式
**重要**:采用分步执行,每完成一步后等待确认再继续,避免一次性处理导致错误
