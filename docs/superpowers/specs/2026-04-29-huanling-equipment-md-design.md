# 幻灵装备整理稿设计

## 目标

把用户提供的 Datatft 装备 HTML 片段整理为一份适合直接放入 `TFT.md` 的发布稿，标题为“幻灵装备”，并保留装备主图与属性小图标，方便后续走图片生成工作流发布。

## 范围

本次只覆盖输出文件：

- `TFT.md`

不在本次范围内：

- 不修改 `images/mdToImage.js`
- 不修改 `images/workflow.js`
- 不保留原始网页 DOM class 作为展示结构
- 不额外补充原 HTML 之外的新装备信息

## 方案选择

采用“Markdown 章节 + 简化 HTML 卡片”的方案。

原因：

- 直接保留原始网页 HTML，现有渲染器无法可靠复现 Datatft 的 class 样式
- 纯截图方案会导致图片文字过小，也不利于后续编辑
- 简化 HTML 卡片可以保留图片和图标，同时让输出更稳定、可控

## 内容结构

输出文件 `TFT.md` 采用以下结构：

1. 顶部元数据
2. 一级标题 `# 幻灵装备`
3. 按装备阶数分段：
   - `## 0阶装备`
   - `## 1阶装备`
   - `## 2阶装备`
   - `## 3阶装备`
   - `## 4阶装备`

每个装备使用统一的简化卡片结构表达，不沿用原始网页三列网格。

## 展示方式

每个装备条目包含：

- 装备主图
- 装备名称
- 属性行
- 效果说明
- 角色专属加成（若原文有）
- 额外规则说明（若原文有）
- 阶数标签

其中：

- 装备主图继续使用原始 CDN 图片地址
- 属性图标继续使用原始 CDN 图标地址
- 属性值按原文顺序保留
- 文案内容尽量原样保留，不做攻略化改写

## 排版原则

- 优先可读性，不追求还原 Datatft 网页布局
- 不使用原始三列卡片网格，避免在 900px 渲染宽度下文字过密
- 同一阶的装备用线性列表呈现，每个装备卡片上下分隔清晰
- 图标保留为小尺寸内联图片，避免被正文图片样式放大

## HTML 边界

允许在 `TFT.md` 中使用少量简化 HTML，包括：

- `<div>`
- `<img>`
- `<span>`
- `<br>`

不保留：

- 原始 `data-v-*` 属性
- 原始 `el-row` / `el-col` / `col-wrapper` 等框架 class
- 原始网页布局相关内联栅格样式

## 元数据

文件顶部补齐：

- `<!-- tags: 幻灵装备, 装备图鉴, Datatft -->`
- `<!-- cover: comp_image.png -->`
- `<!-- backup: huanling-equipment -->`

如无更合适封面图，本次仅保留 `cover` 字段，不额外处理封面资源。

## 验证方式

完成后运行：

1. `node images/workflow.js TFT.md`

重点检查：

- `TFT.md` 可被正常渲染
- 装备主图和属性图标能正常显示
- 单个装备块的文字不挤压、不重叠
- 各阶章节分隔清晰

## 成功标准

- `TFT.md` 被成功覆盖为“幻灵装备”整理稿
- 原 HTML 中的装备图片和属性小图标被保留
- 内容按阶数整理，结构清晰
- 生成图片时具备可读性，不依赖原网页 CSS 才能成立
