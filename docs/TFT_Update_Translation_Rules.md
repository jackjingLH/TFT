# 🚀 TFT版本更新公告翻译规则

## 🚀 标准翻译命令
```
按照@TFT_Update_Translation_Rules.md 规则翻译TFT.txt文件，严格参照TFT_items_translate.js专业术语对照表
```

---

## 📋 翻译规范说明

### 🔧 核心翻译规则：
1. ✅ **语言转换**: 翻译成简体中文，严格参考 TFT_items_translate.js 中的专业术语
2. ✅ **内容纯净**: 不关联任何网址，不添加原文以外内容
3. ✅ **标题处理**: 大标题添加emoji图标，增强视觉效果和吸引力
4. ✅ **数值格式**: 星级采用"数字+星"格式，数字置于名词前面（如"3星亚索"、"4费英雄"）
5. ✅ **语言统一**: 不标注其他语言对照（如避免"绿甲（スピリット ビサージュ）"）
6. ✅ **术语区分**: 严格区分オーグメント（强化符文）和パワーアップ（强化果实）
7. ✅ **结构保持**: 始终保持原文结构，段落不转化成列表

### 🎨 版本更新特殊格式要求：

#### 📊 更新点标记系统
- 🔴 **红色圆点**：加强调整（数值提升、效果增强）
- 🟢 **绿色圆点**：削弱调整（数值降低、效果减弱）
- 🔵 **蓝色圆点**：机制调整（功能变更、BUG修复、重做等）
- 🔧 **扳手图标**：纯BUG修复

#### 🎯 调整描述格式
```
🔵 **英雄名**

属性描述：旧数值 ⇒ 新数值

另一属性：原数值 ⇒ 新数值

🔴 **装备名**

效果描述：原效果 ⇒ 新效果
```

**格式说明**：
- 颜色圆点标注在英雄/装备名称前，表示该单位的整体调整性质
- 英雄/装备名称使用粗体格式，名称后添加空行
- 每个调整项单独成行，项目间添加空行
- 确保Markdown预览时名称和描述分行显示

#### 📱 小红书标题规范
- 独立章节：`## 🏷️ 小红书标题`
- 编号格式：`1. emoji 标题内容`
- 数量要求：5-8个标题
- 内容特点：热门关键词 + 版本重点 + 吸睛表达

### 🔄 版本更新翻译流程

#### 步骤1: 版本信息处理
- 版本号：保持原格式（如"15.4B"）
- 日期：转换为中文日期格式
- 更新目的：口语化翻译，突出重点

#### 步骤2: 内容结构翻译
- ⚠️ **重要**: 严格保持原文顺序和结构
- ❌ **禁止**: 不可单独整理加强削弱分类
- ✅ **正确做法**: 按原文逐项翻译，用颜色圆点标记调整类型
- 📝 **章节划分**: 按原文章节（英雄、装备、羁绊、强化符文、强化果实等）
- 🔄 **顺序保持**: 严格按照原文中每个调整项的出现顺序

#### 步骤3: 格式统一
- 所有数值使用 `旧值 ⇒ 新值` 格式
- 百分比保持%符号
- 时间单位统一（秒、分钟等）
- 颜色圆点前置于每个调整项
- 每个调整项单独成行

#### 步骤4: 小红书标题生成
- 涵盖版本主要变化
- 使用游戏热词（"起飞"、"要火"、"版本答案"等）
- 包含具体英雄或装备名称
- 制造话题性和争议性

### 📝 专业术语处理

#### 🔍 术语来源
- **主要参考**: TFT_items_translate.js（包含1600+条专业术语）
- **覆盖范围**: 英雄名称、装备名称、羁绊名称、强化符文、强化果实等
- **匹配原则**: 自动匹配，确保术语统一性

#### 📋 版本更新专用术语
- **パッチ** → 补丁/版本
- **ナーフ** → 削弱
- **バフ** → 加强
- **調整** → 调整
- **修正** → 修复
- **追加** → 新增
- **削除** → 删除
- **無効化** → 禁用

### 🎯 质量控制要点

- ✅ 确保所有调整点都有对应的圆点标记
- ✅ 数值对比格式统一
- ✅ 专业术语100%准确
- ✅ 大标题使用emoji图标，增强视觉吸引力（调整项前使用颜色圆点）
- ✅ **避免AI痕迹，确保表达地道自然**
- ✅ 小红书标题独立成章节
- ✅ 保持版本更新的严肃性和专业性

### 🚫 避免AI识别的表达技巧

#### 📝 版本更新专用语言风格
- **使用游戏术语**: "砍废了"、"要起飞"、"版本答案"、"无脑强"
- **数值描述**: "贼高"、"超猛"、"稳得一批"
- **平衡性评价**: "太离谱"、"这波削弱到位"、"加强得刚好"
- **预测表达**: "肯定要火"、"估计要凉"、"这下稳了"

#### 🔄 版本更新句式多样化
- **直接表述**: "烬的大招伤害砍了一刀"
- **对比强调**: "这波加强让波比直接起飞"
- **影响预测**: "4费卡这下要重新洗牌了"
- **玩家视角**: "D牌流玩家要哭了"
