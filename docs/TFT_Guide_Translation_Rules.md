# 🎯 TFT攻略指南翻译规则

## 🚀 标准翻译命令
```
按照@TFT_Guide_Translation_Rules.md 规则翻译TFT.txt文件，严格参照TFT_items_translate.js专业术语对照表
```

---

## 📋 翻译规范说明

### 🔧 核心翻译规则：
1. ✅ **语言转换**: 翻译成简体中文，严格参考 TFT_items_translate.js 中的专业术语
2. ✅ **内容纯净**: 不关联任何网址，不添加原文以外内容
3. ✅ **标题处理**:
   - 二级标题添加emoji图标，增强视觉效果和吸引力
   - **仅使用一级标题（#）和二级标题（##）**
   - **禁止使用三级（###）及以下标题**
   - 原文中的三级标题应转换为二级标题或加粗文本
4. ✅ **数值格式**: 星级采用"数字+星"格式，数字置于名词前面（如"3星亚索"、"4费英雄"）
5. ✅ **语言统一**: 不标注其他语言对照（如避免"绿甲（スピリット ビサージュ）"）
6. ✅ **列表格式**: 词汇类列表（强化符文名称罗列）用 / 分割格式
7. ✅ **结构保持**: 始终保持原文结构，段落不转化成列表
8. ✅ **来源声明**: 翻译结束后文章最后添加："来源:XXX"
9. 🚫 **版本保护**: 已发布到平台的翻译内容不得修改，确保内容一致性

### 🎨 沉浸式翻译要求：
- 📖 **攻略文章**: 需要沉浸式翻译TFT内容
- 🏷️ **标题层级**:
  - 一级标题（#）：用于文章主标题
  - 二级标题（##）：用于章节标题
  - **禁止使用三级及以下标题**，需要强调的小节使用**加粗文本**代替
- 🎯 **标题美化**: 大标题添加emoji图标，增强视觉吸引力
- 📱 **小红书标题**: 根据内容生成5-8个趣味吸睛型小红书标题

### 🔄 版本更新公告特殊格式：
- 🔴 红色圆点（加强）
- 🟢 绿色圆点（削弱）  
- 🔵 蓝色圆点（调整）
- 📊 在每个更新点前标注并显示图示

### 步骤1: 准备原文
将原文放入项目根目录的 `TFT.txt` 文件

### 步骤2: 执行翻译
使用标准话术：`按照@docs/TFT_Guide_Translation_Rules.md 规则翻译TFT.txt文件，严格参照TFT_items_translate.js专业术语对照表`

### 步骤3: 输出文件
翻译完成的内容保存到项目根路径，文件名为 `TFT.md`（固定文件名，每次覆盖）

## 🚫 避免AI识别的表达技巧

### 📝 语言风格优化
- **增加口语化**: 使用"贼强"、"起飞"、"稳得一批"等网络用语
- **融入游戏术语**: "上分神器"、"版本答案"、"无脑强"、"躺分"等
- **添加语气词**: "哎"、"嘿"、"说实话"、"不过"等  
- **使用省略表达**: 适当使用"..."、"！"增加自然感

### 🔄 句式多样化
- **避免套路句式**: 减少"通过...实现"、"基于...原则"
- **长短句结合**: 不要段落长度过于均匀
- **主观表达**: 加入"个人觉得"、"我建议"等主观色彩

### 🎮 游戏化表达
- **战斗描述**: "一套秒杀"、"血虐对面"、"无敌碾压"
- **操作用语**: "手速要快"、"卡时机"、"抢先手"  
- **心态用语**: "稳住心态"、"别急"、"慢慢来"

### 📊 常用替换词汇
- "非常强力" → "贼强/超猛"
- "能够实现" → "直接就能"  
- "建议选择" → "推荐用/建议上"
- "具有优势" → "有优势/占便宜"
- "进行操作" → "去操作/直接操作"
