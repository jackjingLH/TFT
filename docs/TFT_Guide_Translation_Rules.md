# 🎯 TFT攻略指南翻译规则

> **文档说明**: 本规则定义TFT攻略翻译的所有标准和流程，确保翻译质量和一致性
> **版本**: v2.0 | **适用赛季**: S16 | **术语库**: jp_to_zh.csv / en_to_zh.csv

---

## 📖 核心翻译规则

### 1️⃣ 语言与术语
- **目标语言**: 简体中文
- **术语来源**:
  - 日译中：`docs/jp_to_zh.csv` (1600+条)
  - 英译中：`docs/en_to_zh.csv` (1600+条)
- **覆盖范围**: 英雄、装备、羁绊、强化符文等
- **匹配原则**: 严格对照术语库，确保统一性
- **语种判断**: 翻译前自动检测原文语言，加载对应术语表

### 2️⃣ 内容完整性
- ✅ **保持结构**: 严格遵循原文结构，段落不转化成列表
- ✅ **内容纯净**: 不添加原文以外内容，不关联任何网址
- ✅ **空标题处理**: 只翻译标题本身，不生成额外内容
- ✅ **来源声明**: 文章末尾添加 "来源:XXX"
- 🚫 **版本保护**: 已发布内容不得修改

### 3️⃣ 格式规范

#### 标题层级（重要）
```markdown
# 文章主标题                    ✅ 一级标题：仅用于文章主标题
## 🎯 章节标题                  ✅ 二级标题：添加emoji图标
**小节强调**                    ✅ 加粗文本：替代三级标题
### 禁止使用                    ❌ 三级及以下标题：一律禁用
```

#### 封面元数据（必需）
```markdown
<!-- subtitle: S16赛季 快速上分神器 -->
<!-- cover: comp_image.png -->
# 阵容标题
```
- **副标题格式**: `赛季信息 + 阵容特点`
- **封面图片**: 使用第一张有意义的阵容图（可选）
- **位置要求**: 必须在一级标题之前

#### 数值格式
- **英雄等级**: `3星辛德拉` ✅ | `辛德拉3星` ❌
- **费用等级**: `4费英雄` ✅ | `英雄4费` ❌
- **符文列表**: `适应性打击 / 生命盔甲 / 救赎` (使用 `/` 分割)

#### 特殊格式：版本更新公告
- 🔴 **加强**: 红色圆点标注
- 🟢 **削弱**: 绿色圆点标注
- 🔵 **调整**: 蓝色圆点标注

### 4️⃣ 空标题映射表
| 原文标题 | 中文翻译 | 内容处理 |
|---------|---------|---------|
| Alt Builds | 🔄 变阵选择 | 保持空 |
| Augments | 🎯 强化符文 | 保持空 |
| Augment Priority | ⭐ 强化符文优先级 | 保持空 |
| Early Comp | 🚀 前期构成 | 保持空 |
| Item Priority | 🎒 装备优先级 | 保持空 |
| Max Cap | 💪 阵容上限 | 保持空 |

> **重要**: 原文空标题翻译后也保持空内容，只翻译标题本身

## ✨ 语言优化技巧

### 📝 自然化表达原则
**目标**: 避免AI痕迹，确保表达地道自然

#### 口语化用词
```
❌ 避免                    ✅ 推荐
非常强力                   贼强 / 超猛
能够实现                   直接就能
建议选择                   推荐用 / 建议上
具有优势                   有优势 / 占便宜
进行操作                   去操作 / 直接操作
```

#### 游戏化术语
- **上分类**: 上分神器、版本答案、无脑强、躺分
- **战斗类**: 一套秒杀、血虐对面、无敌碾压
- **操作类**: 手速要快、卡时机、抢先手
- **心态类**: 稳住心态、别急、慢慢来

#### 语气优化
- **语气词**: 哎、嘿、说实话、不过
- **省略表达**: 适当使用 `...` `!` 增加自然感
- **主观色彩**: 个人觉得、我建议、建议试试

#### 句式多样化
- ✅ 长短句结合，避免段落长度过于均匀
- ✅ 减少套路句式："通过...实现"、"基于...原则"
- ✅ 增加主观表达，避免过于客观

### 🎨 沉浸式翻译增强
- **标题美化**: 二级标题添加emoji图标
- **小红书标题**: 根据内容生成5-8个趣味吸睛型标题
- **段落节奏**: 长短错落有致，增强阅读体验

## 🎯 质量控制清单

### 翻译完成后检查项
- [ ] 专业术语100%符合对应语种的术语表（jp_to_zh.csv / en_to_zh.csv）
- [ ] 标题层级：仅使用一级（#）和二级（##）
- [ ] 封面元数据正确添加在文章开头
- [ ] 数字格式统一：`3星亚索` `4费英雄`
- [ ] 空标题仅翻译标题，内容保持空
- [ ] 文章末尾添加来源声明
- [ ] 语言自然，无AI痕迹
- [ ] 段落结构与原文一致
- [ ] 无额外网址或原文外内容
