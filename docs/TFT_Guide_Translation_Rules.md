# 🎯 TFT攻略指南翻译规则

> **文档说明**: 本规则定义TFT攻略翻译的所有标准和流程，确保翻译质量和一致性
> **版本**: v2.5 | **适用赛季**: S16 | **术语库**: jp_to_zh.csv / en_to_zh.csv

---

## 📖 核心翻译规则

### 1️⃣ 语言与术语
- **目标语言**: 简体中文
- **术语来源**:
  - 日译中：`docs/jp_to_zh.csv` (1600+条)
  - 英译中：`docs/en_to_zh.csv` (1600+条)
- **覆盖范围**: 英雄、装备、羁绊、强化符文等
- **匹配原则**: 严格对照术语库，确保统一性
- **语种判断**: 翻译前自动检测原文语言，加载对应术语表

### 2️⃣ 内容完整性
- ✅ **保持结构**: 严格遵循原文结构，段落不转化成列表
- ✅ **内容纯净**: 不添加原文以外内容，不关联任何网址
- ✅ **空标题处理**: 只翻译标题本身，不生成额外内容
- ✅ **来源声明**: 文章末尾添加 "来源:XXX"
- 🚫 **版本保护**: 已发布内容不得修改

### 3️⃣ 格式规范

#### 文本强调规范（重要）

**小节强调（加粗）**
- **作用**: 替代三级标题，突出重点内容和小节主题
- **使用场景**: 主要用于**名词**类内容
  - 游戏专有名词（英雄、装备、强化符文、羁绊等）
  - 核心概念、重要术语、关键元素
- **比例限制**:
  - 短文（<300字）：最多2-3处
  - 中等文（300-800字）：最多4-6处
  - 长文（>800字）：最多6-8处
- **原则**: 抓取重点名词和术语，避免过度强调

**下划线强调**
- **作用**: 突出细节操作和重要节点
- **使用场景**: 主要用于**短句**类内容
  - 操作时机、关键动作、阶段转换
  - 具体条件、重要提醒、核心步骤
- **格式**: `<u>重要短句</u>`
- **比例限制**:
  - 短文（<300字）：最多1-2处
  - 中等文（300-800字）：最多2-3处
  - 长文（>800字）：最多3-4处
- **原则**: 突出操作短句和关键节点，谨慎使用

#### 标题层级（重要）
```markdown
# 文章主标题                    ✅ 一级标题：仅用于文章主标题
## 🎯 章节标题                  ✅ 二级标题：添加emoji图标
**小节强调**                    ✅ 加粗文本：替代三级标题（注意比例）
<u>重要操作</u>                 ✅ 下划线：突出细节操作（注意比例）
### 禁止使用                    ❌ 三级及以下标题：一律禁用
```

#### 封面元数据（必需）
```markdown
<!-- tags: 根据内容生成 -->
<!-- cover: comp_image.png -->
<!-- backup: 根据标题生成 -->
# 阵容标题
```

**字段说明：**

- **tags（必需）**: 文章标签
  - **格式**: 使用逗号分隔多个标签
  - **生成规则**: 根据阵容内容和特点自动生成合适的标签

- **cover（可选）**: 封面图片路径
  - 使用第一张有意义的阵容图
  - 支持相对路径和绝对路径

- **backup（必需）**: 备份文件夹名称
  - **作用**: 用于自动备份翻译后的阵容到博客项目
  - **格式**: 英文名称，使用短横线连接，全部小写
  - **生成规则**: 根据标题中的核心英雄名或阵容特色自动生成
  - **命名建议**:
    - 优先使用核心英雄的英文名（小写）
    - 多个英雄用短横线连接
    - 可添加特色词：`reroll`、`guide`、`comp`、`flex` 等
    - 保持简洁，2-4个单词为宜

- **位置要求**: 所有元数据必须在一级标题之前

#### 数值格式
- **英雄等级**: `3星辛德拉` ✅ | `辛德拉3星` ❌
- **费用等级**: `4费英雄` ✅ | `英雄4费` ❌
- **符文列表**: `适应性打击 / 生命盔甲 / 救赎` (使用 `/` 分割)

#### 特殊格式：版本更新公告
- 🔴 **加强**: 红色圆点标注
- 🟢 **削弱**: 绿色圆点标注
- 🔵 **调整**: 蓝色圆点标注

## ✨ 语言优化技巧

### 📝 自然化表达原则
**目标**: 避免AI痕迹，确保表达地道自然

#### 口语化用词
```
❌ 避免                    ✅ 推荐
非常强力                   贼强 / 超猛
能够实现                   直接就能
建议选择                   推荐用 / 建议上
具有优势                   有优势 / 占便宜
进行操作                   去操作 / 直接操作
```

#### 游戏化术语
- **上分类**: 上分神器、版本答案、无脑强、躺分
- **战斗类**: 一套秒杀、血虐对面、无敌碾压
- **操作类**: 手速要快、卡时机、抢先手
- **心态类**: 稳住心态、别急、慢慢来

#### 语气优化
- **语气词**: 哎、嘿、说实话、不过
- **省略表达**: 适当使用 `...` `!` 增加自然感
- **主观色彩**: 个人觉得、我建议、建议试试

#### 句式多样化
- ✅ 长短句结合，避免段落长度过于均匀
- ✅ 减少套路句式："通过...实现"、"基于...原则"
- ✅ 增加主观表达，避免过于客观

### 🎨 沉浸式翻译增强
- **标题美化**: 二级标题添加emoji图标
- **小红书标题**: 根据内容生成5-8个趣味吸睛型标题
- **段落节奏**: 长短错落有致，增强阅读体验

## 🎯 质量控制清单

### 翻译完成后检查项
- [ ] 专业术语100%符合对应语种的术语表（jp_to_zh.csv / en_to_zh.csv）
- [ ] **文件编码正确**：确保输出文件使用UTF-8编码，避免乱码和二进制文件错误
- [ ] 标题层级：仅使用一级（#）和二级（##）
- [ ] 封面元数据正确添加在文章开头
  - [ ] **tags** 字段存在且格式正确
  - [ ] **backup** 字段存在且符合命名规范（英文小写，短横线连接）
  - [ ] **cover** 字段（可选）路径正确
- [ ] 数字格式统一：`3星亚索` `4费英雄`
- [ ] 空标题仅翻译标题，内容保持空
- [ ] 文章末尾添加来源声明
- [ ] 语言自然，无AI痕迹
- [ ] 段落结构与原文一致
- [ ] 无额外网址或原文外内容
- [ ] **加粗强调数量符合比例限制**：
  - 短文（<300字）：2-3处
  - 中等文（300-800字）：4-6处
  - 长文（>800字）：6-8处
- [ ] **下划线强调数量符合比例限制**：
  - 短文（<300字）：1-2处
  - 中等文（300-800字）：2-3处
  - 长文（>800字）：3-4处

### 常见错误规避
| 错误类型 | 错误示例 | 正确示例 |
|---------|---------|---------|
| **文件编码** | 文件显示为"二进制文件"或乱码 | UTF-8编码，中文正常显示 |
| 标题层级 | ### 装备选择 | ## 🎒 装备选择 |
| 数字位置 | 亚索3星 | 3星亚索 |
| 语言对照 | 绿甲（Spirit Visage） | 振奋盔甲 |
| 空标题处理 | ## 🎯 强化符文<br>以下是推荐... | ## 🎯 强化符文<br>(空) |
| **backup 字段** | backup: 艾克科加斯 | backup: ekko-chogath |
| **backup 格式** | backup: Ekko_Chogath | backup: ekko-chogath |
| **backup 缺失** | 缺少 backup 字段 | 必须添加 backup 字段 |
| **强调过度** | **所有**内容**都**加粗 | **只突出重点内容**（控制数量） |
| **下划线滥用** | <u>每步操作</u>都<u>下划线</u> | <u>仅关键节点</u>使用下划线（控制数量） |
| **数量超限** | 中等文本8处加粗/5处下划线 | 中等文本4-6处加粗/2-3处下划线 |
