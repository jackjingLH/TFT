# 16.4d热补丁版本上分攻略

## 🎯 版本概述

菲兹削弱后的16.4d热补丁版本，金铲铲之弈推荐以下四套阵容上分（放假前最后一期）。

## ⭐ 第一套：比尔吉沃特九五阵容

玩法回归赛季初风格：

**前中期运营**
- 二、三阶段：优先合成鬼索的狂暴之刃 + 肉装
- 连胜度过四阶段 → 升至7级搭配任意2星4费前排
- 先买装备和2星厄运小姐，搭配1-2个经济型强化符文保存经济

**后期目标**
- 升至9级后寻找 [未收录术语：鲁费莱斯（5费英雄）] 担任主C
- 最终转型为比尔95 [未收录术语：电视局（舒适局面）]，或多法强装备配置

> 可考虑加入菲兹过渡，但后期装备需转移给吉格斯和希瓦娜以提升上限。

## ⭐ 第二套：诺克萨斯九五阵容

因版本一系列小幅加强，重新具备可玩性。

**运营要点**
- 若未能凑齐比尔吉沃特阵容，优先选择此套
- 巴德羁绊激活时：有免费刷新强化符文可进一步解锁，否则不要强行降费
- 经济一般时：激活巴德羁绊 + 一张千珏也可升至9级
- 外围物理系输出多时：可解锁斯卡纳替换塔里克，后期建议换回塞拉斯

## ⭐ 第三套：约德尔人法师九五阵容

奥恩可全程持有作为单挂替换塔里克。法师羁绊的约德尔人阵容依然强势。若无法激活法师羁绊，可直接转约德尔人九五阵容。

## ⭐ 第四套：以绪塔尔岩宝阵容

**暂不推荐。** 双神域（2）回归加强后，以绪塔尔中期过渡压力略有降低，玩法不变。开局有以绪塔尔羁绊时仍可尝试。

## 📊 版本梯队总结

金铲铲之弈当前版本，上述四套阵容强度断层明显，高分局均以此四套为主。

- **想拿第一**：从上述四套选一
- **常规上分**：优先考虑其他可行阵容（具体构成和玩法细节变化不大）

已整理梯队供参考，不知道怎么玩的可以查阅。
