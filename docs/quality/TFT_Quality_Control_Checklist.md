# 🎯 TFT攻略格式控制清单

> **文档说明**: 本文件提供TFT攻略的格式规范检查标准，确保文档格式统一和可读性
> **版本**: v3.0 | **适用范围**: 所有TFT攻略处理项目（工作流A + 工作流B）

---

## 📋 处理完成后检查项

### 🔤 文件编码检查
- [ ] **文件编码正确**：确保输出文件使用UTF-8编码，避免乱码和二进制文件错误

### 📝 格式规范检查
- [ ] **标题层级**：仅使用一级（#）和二级（##）
- [ ] **封面元数据正确添加**在文章开头
  - [ ] **tags** 字段存在且格式正确
  - [ ] **cover** 字段存在且路径正确（必需,默认使用 output/TFT_full.png）
  - [ ] **backup** 字段存在且符合命名规范（英文小写，短横线连接）

### 📊 内容质量检查
- [ ] **数字格式统一**：`3星亚索` `4费英雄` `5比尔吉沃特`
- [ ] **空标题处理**：仅翻译标题，内容保持空
- [ ] **文章末尾添加**来源声明
- [ ] **语言自然**，无AI痕迹
- [ ] **段落结构**与原文一致
- [ ] **无额外网址或原文外内容**

### 🎨 格式多样性检查
- [ ] **格式丰富度**：文章中使用了3种以上不同格式（列表、表格、引用块、加粗、下划线、斜体等）
- [ ] **避免长段落**：超过5行的纯文字段落已拆分为列表或添加格式
- [ ] **对比数据使用表格**：如有英雄属性、装备对比等数据，优先使用表格呈现
- [ ] **列表使用合理**：步骤类内容使用有序列表，并列要点使用无序列表
- [ ] **格式自然分布**：格式在文章中均匀分布，未在某一段落堆砌过多格式

### 🎨 强调格式检查
- [ ] **加粗强调数量符合比例限制**：
  - 短文（<300字）：3-5处
  - 中等文（300-800字）：5-8处
  - 长文（>800字）：7-10处
  - 同一段落多次出现时，可仅首次加粗
- [ ] **下划线强调数量符合比例限制**：
  - 短文（<300字）：2-4处
  - 中等文（300-800字）：3-5处
  - 长文（>800字）：4-6处
- [ ] **引用块使用合理**：
  - 仅在真正重要的核心观点处使用
  - 无数量限制，如无合适内容可不使用
  - 避免滥用，质量优先于数量

## ⚠️ 常见错误规避

| 错误类型 | 错误示例 | 正确示例 |
|---------|---------|---------|
| **文件编码** | 文件显示为"二进制文件"或乱码 | UTF-8编码，中文正常显示 |
| 标题层级 | ### 装备选择 | ## 🎒 装备选择 |
| 数字位置 | 亚索3星 | 3星亚索 |
| 空标题处理 | ## 🎯 强化符文<br>以下是推荐... | ## 🎯 强化符文<br>(空) |
| **cover 缺失** | 缺少 cover 字段 | cover: output/TFT_full.png |
| **cover 格式** | cover：image.png（全角冒号） | cover: image.png（半角冒号+空格） |
| **backup 字段** | backup: 艾克科加斯 | backup: ekko-chogath |
| **backup 格式** | backup: Ekko_Chogath | backup: ekko-chogath |
| **backup 缺失** | 缺少 backup 字段 | 必须添加 backup 字段 |
| **强调过度** | **所有**内容**都**加粗 | **只突出重点内容**（控制数量） |
| **下划线滥用** | <u>每步操作</u>都<u>下划线</u> | <u>仅关键节点</u>使用下划线（控制数量） |
| **数量超限** | 中等文本10处加粗/7处下划线 | 中等文本5-8处加粗/3-5处下划线（引用块无限制） |
