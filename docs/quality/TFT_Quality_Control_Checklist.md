# 🎯 TFT攻略翻译质量控制清单

> **文档说明**: 本文件提供TFT攻略翻译的完整质量控制标准，确保翻译质量和一致性
> **版本**: v2.5 | **适用范围**: 所有TFT攻略翻译项目

---

## 📋 翻译完成后检查项

### 🔤 术语与编码检查
- [ ] **专业术语100%符合**对应语种的术语表（jp_to_zh.csv / en_to_zh.csv）
- [ ] **文件编码正确**：确保输出文件使用UTF-8编码，避免乱码和二进制文件错误

### 📝 格式规范检查
- [ ] **标题层级**：仅使用一级（#）和二级（##）
- [ ] **封面元数据正确添加**在文章开头
  - [ ] **tags** 字段存在且格式正确
  - [ ] **cover** 字段存在且路径正确（必需,默认使用 output/TFT_full.png）
  - [ ] **backup** 字段存在且符合命名规范（英文小写，短横线连接）

### 📊 内容质量检查
- [ ] **数字格式统一**：`3星亚索` `4费英雄` `5比尔吉沃特`
- [ ] **空标题处理**：仅翻译标题，内容保持空
- [ ] **文章末尾添加**来源声明
- [ ] **语言自然**，无AI痕迹
- [ ] **段落结构**与原文一致
- [ ] **无额外网址或原文外内容**

### 🎨 强调格式检查
- [ ] **加粗强调数量符合比例限制**：
  - 短文（<300字）：2-3处
  - 中等文（300-800字）：4-6处
  - 长文（>800字）：6-8处
  - 同一段落多次出现时，可仅首次加粗
- [ ] **下划线强调数量符合比例限制**：
  - 短文（<300字）：1-2处
  - 中等文（300-800字）：2-3处
  - 长文（>800字）：3-4处

## ⚠️ 常见错误规避

| 错误类型 | 错误示例 | 正确示例 |
|---------|---------|---------|
| **文件编码** | 文件显示为"二进制文件"或乱码 | UTF-8编码，中文正常显示 |
| 标题层级 | ### 装备选择 | ## 🎒 装备选择 |
| 数字位置 | 亚索3星 | 3星亚索 |
| 语言对照 | 绿甲（Spirit Visage） | 振奋盔甲 |
| 空标题处理 | ## 🎯 强化符文<br>以下是推荐... | ## 🎯 强化符文<br>(空) |
| **cover 缺失** | 缺少 cover 字段 | cover: output/TFT_full.png |
| **cover 格式** | cover：image.png（全角冒号） | cover: image.png（半角冒号+空格） |
| **backup 字段** | backup: 艾克科加斯 | backup: ekko-chogath |
| **backup 格式** | backup: Ekko_Chogath | backup: ekko-chogath |
| **backup 缺失** | 缺少 backup 字段 | 必须添加 backup 字段 |
| **强调过度** | **所有**内容**都**加粗 | **只突出重点内容**（控制数量） |
| **下划线滥用** | <u>每步操作</u>都<u>下划线</u> | <u>仅关键节点</u>使用下划线（控制数量） |
| **数量超限** | 中等文本8处加粗/5处下划线 | 中等文本4-6处加粗/2-3处下划线 |
